L1.0Objetivos

L1.2Parte A · Las partes clásicas

El fichero siguiente contiene todo lo que Shor hace en un ordenador clásico. La función orden_bruto sustituye a la parte cuántica: es correcta pero exponencial en el número de bits de \(N\).

"""Partes clásicas del algoritmo de Shor (laboratorio L1)."""
from fractions import Fraction
from math import gcd
import random


def orden_bruto(a: int, N: int) -> int:
    """Menor r > 0 con a^r ≡ 1 (mod N). Exponencial en log N: solo para N pequeños."""
    if gcd(a, N) != 1:
        raise ValueError("a y N deben ser coprimos")
    x, r = a % N, 1
    while x != 1:
        x = (x * a) % N
        r += 1
    return r


def convergentes(num: int, den: int):
    """Convergentes p/q de la fracción continua de num/den."""
    a_list = []
    while den:
        q, rem = divmod(num, den)
        a_list.append(q)
        num, den = den, rem
    p_prev, p = 1, a_list[0]
    q_prev, q = 0, 1
    yield Fraction(p, q)
    for ai in a_list[1:]:
        p_prev, p = p, ai * p + p_prev
        q_prev, q = q, ai * q + q_prev
        yield Fraction(p, q)


def orden_desde_medida(y: int, t: int, a: int, N: int):
    """Recupera r a partir de una medida y del registro de t qubits (Q = 2^t)."""
    Q = 2 ** t
    for c in convergentes(y, Q):
        r = c.denominator
        if r >= N:
            break
        if c.numerator == 0:          # s = 0: la medida no informa sobre r
            continue
        # comprobar r y múltiplos pequeños (por si gcd(s, r) > 1)
        for k in range(1, 5):
            R = k * r
            if R < N and pow(a, R, N) == 1:
                return orden_minimo(a, R, N)
    return None


def orden_minimo(a: int, R: int, N: int) -> int:
    """Si a^R ≡ 1, el orden divide a R: quita factores primos mientras a^(R/p) ≡ 1."""
    m, p = R, 2
    while p <= m:
        while m % p == 0 and pow(a, m // p, N) == 1:
            m //= p
        p += 1
    return m


def factores_desde_orden(a: int, r: int, N: int):
    """Paso clásico final. Devuelve ((p, q), "ok") o (None, motivo del fallo)."""
    if r % 2 == 1:
        return None, "r impar"
    x = pow(a, r // 2, N)
    if x == N - 1:
        return None, "a^(r/2) ≡ −1 (mod N)"
    p, q = gcd(x - 1, N), gcd(x + 1, N)
    return (p, q), "ok"


def shor_clasico(N: int, rng=None, max_intentos=20, verbose=True):
    """Reducción de Shor con el cálculo del orden hecho por fuerza bruta."""
    rng = rng or random.Random()
    if N % 2 == 0:
        return 2, N // 2
    for intento in range(1, max_intentos + 1):
        a = rng.randrange(2, N - 1)
        g = gcd(a, N)
        if g > 1:
            if verbose:
                print(f"[{intento}] a={a}: gcd(a,N)={g} -> factor por suerte")
            return g, N // g
        r = orden_bruto(a, N)
        res, motivo = factores_desde_orden(a, r, N)
        if verbose:
            print(f"[{intento}] a={a}: r={r} -> {motivo}")
        if res and 1 < res[0] < N:
            return res[0], N // res[0]
    return None


if __name__ == "__main__":
    for N in (15, 21, 35, 91, 143, 3233):
        print(f"N={N}:", shor_clasico(N, rng=random.Random(N)))
    # recuperación por fracciones continuas: N=15, a=7, r=4, t=8 (Q=256)
    for y in (0, 64, 128, 192):
        print("y =", y, "->", orden_desde_medida(y, 8, 7, 15))

L1.4Parte C · El circuito de búsqueda de orden en Qiskit

El circuito tiene un registro de fase de \(t = 2m\) qubits y un registro de trabajo de \(m = \lceil \log_2(N + 1)\rceil\) qubits inicializado a \(|1\rangle\). El qubit de fase \(k\) controla una multiplicación por \(a^{2^k} \bmod N\); tras la QFT inversa se mide el registro de fase.

Una multiplicación modular correcta

La operación \(|x\rangle \mapsto |ax \bmod N\rangle\) es una permutación de los estados \(0 \le x < N\) cuando \(\gcd(a, N) = 1\); completándola con la identidad para \(x \ge N\) se obtiene una matriz unitaria. La función mult_mod_gate construye esa matriz de permutación y Qiskit la sintetiza en puertas. Es correcta para cualquier \(a\) y \(N\), pero su tamaño es \(2^m \times 2^m\): no escala. Un circuito escalable implementa la multiplicación con sumadores reversibles (por ejemplo, los de Beauregard [3] o las construcciones de [4]).

Para \(N = 15\), \(a = 7\) existe una construcción compacta conocida: tres SWAP y cuatro X. El script comprueba con Operator que coincide con \(x \mapsto 7x \bmod 15\) en todos los estados \(x = 1, \dots, 14\) antes de usarla; no la aceptes sin esa verificación (el orden de los SWAP es fácil de invertir por error, y entonces el circuito implementa otra permutación).

"""Búsqueda de orden (parte cuántica de Shor) con Qiskit 2.x y Qiskit Aer.

Uso:  python shor_qiskit.py [N] [a] [--swaps] [--ruido P]
      (por defecto N=15, a=7; --swaps solo para N=15, a=7)
"""
import argparse
from collections import Counter

import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit.circuit.library import QFTGate, UnitaryGate
from qiskit.quantum_info import Operator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_aer.noise import NoiseModel, depolarizing_error
from qiskit_aer.primitives import SamplerV2

from shor_clasico import orden_desde_medida, factores_desde_orden


def mult_mod_gate(a: int, N: int, m: int) -> UnitaryGate:
    """|x> -> |a·x mod N> para x < N; identidad para x >= N (es una permutación)."""
    dim = 2 ** m
    U = np.zeros((dim, dim))
    for x in range(dim):
        U[(a * x) % N if x < N else x, x] = 1
    return UnitaryGate(U, label=f"×{a} mod {N}")


def mult7_mod15_swaps() -> QuantumCircuit:
    """x -> 7x mod 15 con 3 SWAP y 4 X (válido para x = 1..14)."""
    qc = QuantumCircuit(4, name="×7 mod 15")
    qc.swap(0, 1)
    qc.swap(1, 2)
    qc.swap(2, 3)
    qc.x(range(4))
    return qc


def comprobar_swaps():
    P = Operator(mult7_mod15_swaps()).data
    for x in range(1, 15):
        assert np.argmax(np.abs(P[:, x])) == (7 * x) % 15, x
    print("Comprobación: SWAP+X implementa x -> 7x mod 15 en x = 1..14")


def circuito_orden(a: int, N: int, t: int, m: int, swaps: bool = False) -> QuantumCircuit:
    fase = QuantumRegister(t, "fase")
    trabajo = QuantumRegister(m, "x")
    c = ClassicalRegister(t, "c")
    qc = QuantumCircuit(fase, trabajo, c)
    qc.h(fase)
    qc.x(trabajo[0])                            # registro de trabajo = |1>
    for k in range(t):
        ak = pow(a, 2 ** k, N)                  # a^(2^k) mod N, precalculado clásicamente
        if ak == 1:
            continue                            # multiplicar por 1 es la identidad
        if swaps:                               # a^(2^k) = 7^j: aplicar j veces ×7
            j = next(j for j in range(1, 4) if pow(7, j, 15) == ak)
            for _ in range(j):
                qc.append(mult7_mod15_swaps().to_gate().control(1), [fase[k], *trabajo])
        else:
            qc.append(mult_mod_gate(ak, N, m).control(1), [fase[k], *trabajo])
    qc.append(QFTGate(t).inverse(), fase)
    qc.measure(fase, c)
    return qc


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("N", nargs="?", type=int, default=15)
    ap.add_argument("a", nargs="?", type=int, default=7)
    ap.add_argument("--swaps", action="store_true")
    ap.add_argument("--ruido", type=float, default=0.0, help="error despolarizante por CX")
    ap.add_argument("--shots", type=int, default=2048)
    args = ap.parse_args()
    N, A = args.N, args.a
    if args.swaps:
        assert (N, A) == (15, 7), "--swaps solo está implementado para N=15, a=7"
        comprobar_swaps()

    m = N.bit_length()          # qubits de trabajo
    t = 2 * m                   # qubits de fase: Q = 2^t >= N^2
    qc = circuito_orden(A, N, t, m, swaps=args.swaps)

    noise = None
    if args.ruido > 0:
        noise = NoiseModel()
        noise.add_all_qubit_quantum_error(depolarizing_error(args.ruido, 2), ["cx"])
    # Transpilar a un conjunto de puertas universal sencillo para poder contar CX
    pm = generate_preset_pass_manager(optimization_level=1,
                                      basis_gates=["cx", "rz", "sx", "x"], seed_transpiler=1)
    isa = pm.run(qc)
    print(f"N={N}, a={A}: {qc.num_qubits} qubits, profundidad {isa.depth()}, "
          f"CX = {isa.count_ops().get('cx', 0)}")

    opciones = {"backend_options": {"noise_model": noise}} if noise else {}
    sampler = SamplerV2(default_shots=args.shots, seed=1234, options=opciones)
    counts = sampler.run([isa]).result()[0].data.c.get_counts()

    Q = 2 ** t
    print(f"Medidas más frecuentes (Q = 2^{t} = {Q}):")
    for bits, n in sorted(counts.items(), key=lambda kv: -kv[1])[:8]:
        y = int(bits, 2)
        print(f"  y={y:4d}  y/Q={y / Q:.4f}  n={n:4d}  r={orden_desde_medida(y, t, A, N)}")

    votos = Counter()
    for bits, n in counts.items():
        votos[orden_desde_medida(int(bits, 2), t, A, N)] += n
    print("Órdenes candidatos (votos):", dict(votos))
    votos.pop(None, None)
    r = votos.most_common(1)[0][0]
    res, motivo = factores_desde_orden(A, r, N)
    if res:
        print(f"r={r}: {A}^{r // 2} mod {N} = {pow(A, r // 2, N)} -> factores {res[0]} x {res[1]}")
    else:
        print(f"r={r}: fallo ({motivo}); repetir con otra a")


if __name__ == "__main__":
    main()

Cómo no «demostrar» Shor

Las implementaciones que sustituyen la exponenciación modular por un circuito diseñado sabiendo ya el periodo, o que reducen el registro a lo que el resultado conocido necesita, pueden «factorizar» cualquier número con dos qubits [2]. Tu circuito de la tarea C1 genérica no usa el periodo: solo usa \(a^{2^k} \bmod N\), que cualquier atacante calcula clásicamente. La versión con SWAP sí es específica de \((15, 7)\), pero se deriva de la multiplicación, no del resultado.

print("Gidney–Ekerå 2019: fórmulas de coste lógico para RSA-n")
print(f"{'n':>6} {'qubits lógicos':>15} {'Toffoli':>10} {'prof. medida':>13}")
for n in (1024, 2048, 3072, 4096):
    lg = log2(n)
    qubits = 3 * n + 0.002 * n * lg
    toffoli = 0.3 * n**3 + 0.0005 * n**3 * lg
    depth = 500 * n**2 + n**2 * lg
    print(f"{n:>6} {qubits:>15,.0f} {toffoli:>10.2e} {depth:>13.2e}")

# Tasas de Toffoli implícitas (tiempo total / número de Toffoli)
casos = {"Gidney–Ekerå 2019": (3e9, 8 * 3600), "Gidney 2025": (6.5e9, 4.96 * 86400)}
for nombre, (tof, seg) in casos.items():
    print(f"{nombre}: {tof / seg:,.0f} Toffoli/s")

  2. D2. Gidney (2025) [6] usa 1 399 qubits lógicos y 897 864 físicos: ¿cuántos qubits físicos por qubit lógico hay en promedio? ¿En qué se gasta la diferencia además del almacenamiento (fábricas o cultivo de estados mágicos, enrutamiento)?
  3. D3. Tu circuito para \(N = 15\) tiene 224 CX. Si una puerta de dos qubits tiene un error del 0,1 %, ¿qué probabilidad aproximada hay de que el circuito completo se ejecute sin ningún error? ¿Y un circuito de \(10^9\) puertas? Concluye por qué no hay Shor útil sin corrección de errores.
  4. D4. Las estimaciones de 2026 para ECDLP-256 (≤ 1 200 qubits lógicos, ≤ \(9\cdot 10^7\) Toffoli, menos de 500 000 físicos, minutos) [7] son más bajas que las de RSA-2048. ¿Qué implica para el orden de migración de ECDH/X25519, ECDSA y RSA en una organización?
  5. D5. Aplica la desigualdad de Mosca a un sistema real que conozcas (nómina, historia clínica, firmware de un dispositivo IoT). Justifica tus valores de \(x\) e \(y\) y usa como \(z\) los rangos de la encuesta del Global Risk Institute publicada en marzo de 2026 (tema 1, §1.9).
Orientación para D1–D3 (consúltala después de intentarlo)

D1: ≈ 12 400 qubits lógicos y \(\approx 2{,}1\cdot 10^{10}\) Toffoli; el coste crece ≈ 8 veces (cúbico) al doblar \(n\), así que alargar claves solo compra un factor polinómico: no es una defensa. D2: ≈ 640 físicos por lógico de media. D3: \(0{,}999^{224} \approx 0{,}80\); para \(10^9\) puertas, \(0{,}999^{10^9} \approx e^{-10^6}\), es decir, cero.
