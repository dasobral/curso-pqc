Preparación del entorno

Todos los laboratorios comparten un entorno de Python aislado. Cada guía indica los paquetes y versiones concretos que necesita y cómo comprobar que funcionan.

$ python3 --version          # 3.12 o posterior
$ python3 -m venv ~/pqc-lab && source ~/pqc-lab/bin/activate
$ python -m pip install --upgrade pip numpy
$ openssl version            # 3.5 o posterior para ML-KEM, ML-DSA y SLH-DSA nativos

Si tu sistema trae una versión de OpenSSL anterior a la 3.5, la guía L4 explica alternativas. Los laboratorios funcionan en Linux, macOS y Windows con WSL.

Resultado final y autoevaluación

Cada laboratorio termina con un apartado «Resultado final», que dice qué deberías tener al acabar (código, gráficas y respuestas razonadas en tu propio cuaderno), y una tabla de autoevaluación para comprobar tu trabajo y saber qué sección repasar.

Buenas prácticas
  • Anota las versiones exactas de las herramientas que uses; la salida cambia entre versiones.
  • No reutilices el código de juguete fuera del laboratorio.
  • Cuando un resultado no coincida con la salida esperada, averigua por qué antes de seguir: suele ser la parte que más enseña.
