Firmas ML-DSA y SLH-DSA

Del mecanismo a la herramienta: medirás la tasa de rechazo de Fiat–Shamir con abortos, firmarás con ML-DSA y SLH-DSA reales en OpenSSL y liboqs, construirás firmas de Lamport y un árbol de Merkle para entender las firmas basadas en hash, y falsificarás una firma reutilizando una clave de un solo uso.

Duración
3 h (+ redacción de tus notas)
Nivel
Intermedio
Requisitos
Python 3.12+, OpenSSL ≥ 3.5, línea de órdenes
Actualizado
Septiembre 2026

L3.0Objetivos

  • Relacionar los parámetros de un esquema Fiat–Shamir con abortos (\(\gamma_1\), \(\gamma_2\), \(\beta\)) con su tasa de rechazo, midiéndola.
  • Generar claves, firmar y verificar con ML-DSA (FIPS 204) y SLH-DSA (FIPS 205) usando OpenSSL 3.5 y liboqs-python, incluidos contextos, firma determinista y claves en formato semilla.
  • Implementar firmas de Lamport y un árbol de Merkle, y demostrar por qué reutilizar una clave de un solo uso es catastrófico.
  • Comparar tamaños y tiempos de ML-DSA, SLH-DSA, Falcon/FN-DSA, Ed25519, ECDSA y RSA, y razonar sobre su impacto en certificados y protocolos.
  • Argumentar decisiones de uso: puro frente a pre-hash, cadenas de contexto, determinista frente a hedged y gestión del estado en LMS/XMSS.

Antes del laboratorio conviene haber leído el Tema 4 (especificación de ML-DSA y SLH-DSA) y jugado con el ejemplo interactivo E3. La base matemática (MLWE, MSIS, funciones hash) está en el Tema 3.

L3.2Parte A · Fiat–Shamir con abortos en miniatura

El programa siguiente implementa el núcleo de ML-DSA sin compresión de \(\mathbf{t}\) ni pistas: la clave pública es \(\mathbf{t} = \mathbf{A}\mathbf{s}_1 + \mathbf{s}_2\) completa y el verificador comprueba \(\operatorname{HighBits}(\mathbf{A}\mathbf{z} - c\mathbf{t}) = \mathbf{w}_1\), que es correcto gracias al segundo rechazo. Usa \(q\) real, \(n = 64\) (para que Python puro sea rápido) y SHAKE-256 de hashlib. La versión con Power2Round y pistas está en el ejemplo E3.

"""Fiat–Shamir con abortos en miniatura (estructura de ML-DSA sin compresión de t ni pistas).

Mide cuántos intentos necesita la firma en función de γ1, γ2 y β = τ·η,
y lo compara con la estimación de FIPS 204: E[intentos] ≈ exp(n·β·(ℓ/γ1 + k/γ2)).
Solo docencia: sin tiempo constante, sin codificaciones, parámetros de juguete.
"""
import hashlib
import math
import secrets
import sys

Q = 8380417                      # módulo de ML-DSA


def shake(data: bytes, n: int) -> bytes:
    return hashlib.shake_256(data).digest(n)


def mul(a, b, n):
    """Producto en Z_q[X]/(X^n + 1), de libro."""
    c = [0] * n
    for i, ai in enumerate(a):
        if ai == 0:
            continue
        for j, bj in enumerate(b):
            k = i + j
            if k < n:
                c[k] += ai * bj
            else:
                c[k - n] -= ai * bj
    return [x % Q for x in c]


def centered(x, m):
    """Representante de x mod m en (−m/2, m/2]."""
    r = x % m
    return r - m if r > m // 2 else r


def decompose(r, g2):
    r %= Q
    r0 = centered(r, 2 * g2)
    if r - r0 == Q - 1:
        return 0, r0 - 1
    return (r - r0) // (2 * g2), r0


def sample_in_ball(seed, n, tau):
    """Polinomio con exactamente tau coeficientes ±1 (como SampleInBall de FIPS 204)."""
    length = 8 + 8 * n
    stream = shake(seed, length)
    signs = int.from_bytes(stream[:8], "little")
    c, pos = [0] * n, 8
    for i in range(n - tau, n):
        while True:
            if pos == length:                     # XOF: pedir más salida si hace falta
                length *= 2
                stream = shake(seed, length)
            j = stream[pos] % n                   # n divide a 256: sin sesgo
            pos += 1
            if j <= i:
                break
        c[i], c[j] = c[j], 1 - 2 * (signs & 1)
        signs >>= 1
    return c


class Toy:
    def __init__(self, n=64, k=4, l=4, eta=2, tau=39, g1=2**17, g2=(Q - 1) // 88):
        self.n, self.k, self.l, self.eta, self.tau = n, k, l, eta, tau
        self.g1, self.g2, self.beta = g1, g2, tau * eta
        rnd = secrets.SystemRandom()
        self.A = [[[rnd.randrange(Q) for _ in range(n)] for _ in range(l)] for _ in range(k)]
        self.s1 = [[rnd.randint(-eta, eta) for _ in range(n)] for _ in range(l)]
        self.s2 = [[rnd.randint(-eta, eta) for _ in range(n)] for _ in range(k)]
        self.t = [self._add(self._row(i, self.s1), self.s2[i]) for i in range(k)]

    def _row(self, i, v):
        acc = [0] * self.n
        for j in range(self.l):
            acc = self._add(acc, mul(self.A[i][j], v[j], self.n))
        return acc

    @staticmethod
    def _add(a, b):
        return [(x + y) % Q for x, y in zip(a, b)]

    def sign(self, msg: bytes):
        n, rnd, attempts = self.n, secrets.SystemRandom(), 0
        while True:
            attempts += 1
            y = [[rnd.randint(-self.g1 + 1, self.g1) for _ in range(n)] for _ in range(self.l)]
            w = [self._row(i, y) for i in range(self.k)]
            w1 = bytes(decompose(x, self.g2)[0] for poly in w for x in poly)
            c_seed = shake(msg + w1, 32)
            c = sample_in_ball(c_seed, n, self.tau)
            z = [[centered(yi + ci, Q) for yi, ci in zip(y[j], mul(c, self.s1[j], n))] for j in range(self.l)]
            if max(abs(x) for p in z for x in p) >= self.g1 - self.beta:
                continue                                  # rechazo 1: z revelaría c·s1
            cs2 = [mul(c, self.s2[i], n) for i in range(self.k)]
            r0 = [decompose(w[i][j] - cs2[i][j], self.g2)[1] for i in range(self.k) for j in range(n)]
            if max(abs(x) for x in r0) >= self.g2 - self.beta:
                continue                                  # rechazo 2: HighBits(w − c·s2) ≠ w1
            return (c_seed, z), attempts

    def verify(self, msg, sig):
        c_seed, z = sig
        if max(abs(x) for p in z for x in p) >= self.g1 - self.beta:
            return False
        c = sample_in_ball(c_seed, self.n, self.tau)
        zq = [[x % Q for x in p] for p in z]
        w1 = bytes(decompose(a - b, self.g2)[0]
                   for i in range(self.k)
                   for a, b in zip(self._row(i, zq), mul(c, self.t[i], self.n)))
        return shake(msg + w1, 32) == c_seed


def expected(n, k, l, beta, g1, g2):
    return math.exp(n * beta * (l / g1 + k / g2))


if __name__ == "__main__":
    trials = int(sys.argv[1]) if len(sys.argv) > 1 else 100
    print(f"{'n':>4} {'γ1':>8} {'γ2':>7} {'β':>4} {'intentos/firma':>15} {'predicho':>9} {'verifica':>9}")
    for n, g1, g2, tau in [(64, 2**17, (Q - 1) // 88, 39), (64, 2**15, (Q - 1) // 88, 39),
                           (64, 2**13, (Q - 1) // 88, 39), (64, 2**17, (Q - 1) // 32, 39),
                           (64, 2**17, (Q - 1) // 88, 60), (128, 2**17, (Q - 1) // 88, 39)]:
        toy = Toy(n=n, g1=g1, g2=g2, tau=tau)
        total, ok = 0, 0
        for i in range(trials):
            sig, att = toy.sign(b"mensaje %d" % i)
            total += att
            ok += toy.verify(b"mensaje %d" % i, sig)
        pred = expected(n, toy.k, toy.l, toy.beta, g1, g2)
        print(f"{n:>4} {g1:>8} {g2:>7} {toy.beta:>4} {total / trials:>15.2f} {pred:>9.2f} {ok:>5}/{trials}")
    sig, _ = toy.sign(b"original")
    print("¿Verifica un mensaje alterado?", toy.verify(b"alterado", sig))

  • -pkeyopt context-string:… fija la cadena de contexto (hasta 255 bytes) de FIPS 204; el verificador debe usar la misma.
  • -pkeyopt deterministic:1 activa la variante determinista (rnd = 32 bytes a cero): dos firmas del mismo mensaje son idénticas. Sin ella (por defecto, hedged), cada firma es distinta.
  • -pkeyopt hexseed:… deriva la clave de una semilla \(\xi\) dada. Con la semilla del ejemplo, el SHA-256 de tu clave pública PEM debe empezar por e8c997db: es un vector de prueba reproducible.
  • -provparam ml-dsa.output_formats=seed-only guarda solo la semilla (128 bytes de PEM frente a 3 613): la clave expandida se recalcula al cargarla. OpenSSL documenta además el parámetro mu (firmar un \(\mu\) calculado fuera) y message-encoding:0 (firmar \(M'\) sin formatear, solo para pruebas) [4].

L3.4Parte C · liboqs-python

liboqs ofrece las mismas primitivas desde Python, C, Go, Java o Rust. Los nombres de SLH-DSA siguen el convenio de liboqs (SLH_DSA_PURE_SHA2_128F para la variante pura; también existen las variantes pre-hash, como SLH_DSA_SHA2_256_PREHASH_SHA2_128F).

"""ML-DSA y SLH-DSA con liboqs-python: firmar, verificar, contexto."""
import oqs

msg = b"Acta de la reunion, 24/09/2026"
for alg in ["ML-DSA-65", "SLH_DSA_PURE_SHA2_128F"]:
    with oqs.Signature(alg) as signer:
        pk = signer.generate_keypair()
        sig = signer.sign(msg)
        print(f"{alg}: pk {len(pk)} B, firma {len(sig)} B")
        print("  verifica:", signer.verify(msg, sig, pk))
        print("  mensaje alterado:", signer.verify(msg + b"!", sig, pk))
        if signer.details["sig_with_ctx_support"]:
            s2 = signer.sign_with_ctx_str(msg, b"actas-v1")
            print("  con contexto correcto:", signer.verify_with_ctx_str(msg, s2, b"actas-v1", pk))
            print("  con otro contexto:   ", signer.verify_with_ctx_str(msg, s2, b"facturas-v1", pk))
            print("  sin contexto:        ", signer.verify(msg, s2, pk))

L3.5Parte D · Lamport, Merkle y el peligro del estado

SLH-DSA, LMS y XMSS se construyen a partir de firmas de un solo uso (Lamport, Winternitz/WOTS+) y árboles de Merkle [7][8]. Una firma de Lamport de un resumen de 256 bits revela, para cada bit, una de las dos preimágenes secretas de esa posición. Si la misma clave firma varios mensajes, el atacante acumula preimágenes de ambos valores en cada vez más posiciones y acaba pudiendo firmar mensajes nuevos.

"""Firmas de un solo uso de Lamport, árbol de Merkle y falsificación por reutilización.

Idea de SLH-DSA/LMS/XMSS con la pieza más simple posible. Solo docencia.
"""
import hashlib
import secrets
import time

H = lambda b: hashlib.sha256(b).digest()
N = 256                                     # bits del resumen que se firma


def bits(msg: bytes):
    d = int.from_bytes(H(msg), "big")
    return [(d >> (N - 1 - i)) & 1 for i in range(N)]


# ------------------------------------------------------------------ Lamport
def lamport_keygen():
    sk = [[secrets.token_bytes(32), secrets.token_bytes(32)] for _ in range(N)]
    pk = [[H(a), H(b)] for a, b in sk]
    return sk, pk


def lamport_sign(sk, msg):
    return [sk[i][b] for i, b in enumerate(bits(msg))]     # revela una preimagen por bit


def lamport_verify(pk, msg, sig):
    return all(H(s) == pk[i][b] for i, (s, b) in enumerate(zip(sig, bits(msg))))


def pk_bytes(pk):
    return b"".join(a + b for a, b in pk)


# ------------------------------------------------------------------ Merkle
def merkle_tree(leaves):
    levels = [leaves]
    while len(levels[-1]) > 1:
        lv = levels[-1]
        levels.append([H(lv[i] + lv[i + 1]) for i in range(0, len(lv), 2)])
    return levels                                            # levels[-1][0] es la raíz


def auth_path(levels, idx):
    path = []
    for lv in levels[:-1]:
        path.append(lv[idx ^ 1])                             # hermano en cada nivel
        idx >>= 1
    return path


def root_from_path(leaf, idx, path):
    node = leaf
    for sib in path:
        node = H(node + sib) if idx % 2 == 0 else H(sib + node)
        idx >>= 1
    return node


class MerkleSigner:
    """Esquema con estado: 2^h claves de Lamport bajo una única raíz pública."""

    def __init__(self, h=4):
        self.keys = [lamport_keygen() for _ in range(2 ** h)]
        self.levels = merkle_tree([H(pk_bytes(pk)) for _, pk in self.keys])
        self.root = self.levels[-1][0]
        self.next = 0                                        # ESTADO: nunca debe repetirse

    def sign(self, msg):
        if self.next >= len(self.keys):
            raise RuntimeError("claves agotadas")
        i, self.next = self.next, self.next + 1              # actualizar el estado ANTES de firmar
        sk, pk = self.keys[i]
        return i, lamport_sign(sk, msg), pk, auth_path(self.levels, i)


def merkle_verify(root, msg, sig):
    i, ots, pk, path = sig
    return lamport_verify(pk, msg, ots) and root_from_path(H(pk_bytes(pk)), i, path) == root


# ------------------------------------------------------------------ ataque por reutilización
def forge(pk, signed, target_prefix, max_tries=10**7):
    """Con varias firmas de la MISMA clave, busca un mensaje nuevo firmable."""
    known = [dict() for _ in range(N)]
    for msg, sig in signed:
        for i, b in enumerate(bits(msg)):
            known[i][b] = sig[i]
    fixed = sum(1 for k in known if len(k) == 1)
    for t in range(max_tries):
        m = target_prefix + b" #" + str(t).encode()
        bm = bits(m)
        if all(bm[i] in known[i] for i in range(N)):
            return m, [known[i][bm[i]] for i in range(N)], fixed, t + 1
    return None, None, fixed, max_tries


if __name__ == "__main__":
    sk, pk = lamport_keygen()
    sig = lamport_sign(sk, b"hola")
    print("Lamport: |pk| =", len(pk_bytes(pk)), "B, |sig| =", sum(map(len, sig)), "B")
    print("  verifica 'hola':", lamport_verify(pk, b"hola", sig), "· verifica 'hola!':", lamport_verify(pk, b"hola!", sig))

    ms = MerkleSigner(h=4)
    s = ms.sign(b"primer documento")
    print("Merkle h=4: raíz", ms.root.hex()[:16] + "…", "· camino de autenticación:", len(s[3]), "nodos")
    print("  verifica:", merkle_verify(ms.root, b"primer documento", s), "· índice usado:", s[0], "· siguiente:", ms.next)

    print("\nReutilizar UNA clave de Lamport k veces:")
    for k in range(2, 7):
        sk, pk = lamport_keygen()
        signed = [(b"mensaje legitimo %d" % j, None) for j in range(k)]
        signed = [(m, lamport_sign(sk, m)) for m, _ in signed]
        t0 = time.time()
        tries = 2 * 10**5 if k >= 4 else 10**4
        m, fsig, fixed, used = forge(pk, signed, b"Transferir 1000000 EUR a Mallory", max_tries=tries)
        dt = time.time() - t0
        if m:
            print(f"  k={k}: {fixed:3d} bits fijados (esperado ≈ {256 / 2**(k-1):.0f}) → FALSIFICADA en {used} intentos "
                  f"({dt:.2f} s): {m.decode()!r} · verifica: {lamport_verify(pk, m, fsig)}")
        else:
            print(f"  k={k}: {fixed:3d} bits fijados (esperado ≈ {256 / 2**(k-1):.0f}) → sin éxito en {used} intentos "

Tras \(k\) firmas con la misma clave, una posición queda «fijada» (solo se conoce una preimagen) si los \(k\) resúmenes coinciden en ese bit, lo que ocurre con probabilidad \(2^{1-k}\); en media quedan \(256 \cdot 2^{1-k}\) bits fijados y el coste de falsificar es \(\approx 2^{256 \cdot 2^{1-k}}\) hashes. Con cinco firmas, \(2^{17}\): segundos en un portátil. Los mensajes legítimos del programa son fijos, así que el número de bits fijados es reproducible; el mensaje falsificado verifica con la clave pública original.

ALG = "XMSS-SHA2_10_256"                     # RFC 8391, árbol de altura 10: 2^10 firmas

              f" · restantes {signer.sigs_remaining()}")
    snapshot = signer.export_secret_key()     # «copia de seguridad» de la clave CON su estado actual
    print("clave privada exportada:", len(snapshot), "B")

Firmas con estado en producción

En LMS y XMSS, firmar dos mensajes con el mismo índice rompe la seguridad del esquema. El estado se pierde de formas banales: restaurar una copia de seguridad o una instantánea de máquina virtual, clonar un contenedor con la clave, ejecutar dos firmantes en paralelo sin repartir los índices, o que el proceso caiga entre firmar y guardar el contador. Por eso NIST SP 800-208 [9] limita su uso a casos con pocas firmas y control estricto de la clave (típicamente, firma de firmware), y exige generar las claves y firmar dentro de módulos criptográficos hardware validados FIPS 140 de nivel 3 o superior, que no permitan exportar la clave privada ni siquiera cifrada. La regla de implementación es: actualizar el estado en almacenamiento no volátil antes de devolver la firma.

"""Tamaños y tiempos de firmas post-cuánticas con liboqs-python."""
import time
import oqs

ALGS = ["ML-DSA-44", "ML-DSA-65", "ML-DSA-87",
        "SLH_DSA_PURE_SHA2_128S", "SLH_DSA_PURE_SHA2_128F", "Falcon-512"]
MSG = b"x" * 1024


def bench(fn, min_time=0.5):
    n, t0 = 0, time.perf_counter()
    while True:
        fn()
        n += 1
        dt = time.perf_counter() - t0
        if dt >= min_time and n >= 3:
            return dt / n * 1e3            # ms por operación


print(f"liboqs {oqs.oqs_version()} · liboqs-python {oqs.oqs_python_version()}")

#!/usr/bin/env bash

set -e

            ML-DSA-44 ML-DSA-65 ML-DSA-87 SLH-DSA-SHA2-128s SLH-DSA-SHA2-128f; do
  n=${spec%% *}
  openssl genpkey -algorithm $spec -out t_$n.key 2>/dev/null
  openssl req -x509 -new -key t_$n.key -subj /CN=curso-pqc-L3 -days 30 -out t_$n.crt
  case $n in
    EC|RSA) openssl dgst -sha256 -sign t_$n.key -out t_$n.sig msg.txt ;;
    *)      openssl pkeyutl -sign -rawin -inkey t_$n.key -in msg.txt -out t_$n.sig ;;
  esac
  printf '%-20s %6d %6d %6d\n' $n \
    $(openssl pkey -in t_$n.key -pubout -outform DER | wc -c) \
    $(openssl x509 -in t_$n.crt -outform DER | wc -c) $(wc -c < t_$n.sig)
done

Ideas clave
  • La tasa de rechazo de ML-DSA sigue el modelo \(\exp\bigl(n\beta(\ell/\gamma_1 + k/\gamma_2)\bigr)\): agrandar \(\gamma\) reduce intentos pero agranda la firma o reduce la seguridad.
  • OpenSSL 3.5 LTS firma y verifica ML-DSA y SLH-DSA con pkeyutl -rawin, y admite contexto, firma determinista, claves en formato semilla y certificados X.509.
  • ML-DSA firma y verifica a velocidades comparables a RSA/ECDSA, pero sus firmas son unas 40 veces mayores que las de Ed25519; SLH-DSA es mucho más lento al firmar y aún mayor, con la ventaja de depender solo de funciones hash.
  • Reutilizar una clave de un solo uso es catastrófico: cada firma adicional reduce a la mitad el exponente del coste de falsificación. En LMS/XMSS eso convierte la gestión del estado en un requisito de seguridad.
